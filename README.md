# Canvas Task Tracker

A lightweight Canvas task tracker UI that lets students add, manage, and prioritize
coursework tasks in one place. The demo stores tasks in browser local storage and
includes a mock Canvas connection button that can be wired to real OAuth flows.

## Features

- Task creation with type, status, reminders, and repeating cadence.
- Filters for priority, course, and status plus sorting by due date or course.
- Weekly dashboard stats, export/import for backups, and a calendar view.

## Getting started

Open `index.html` directly in a browser, or run a simple web server:

```bash
python3 -m http.server 5173
```

Then visit `http://localhost:5173`.
